`index.html` bundles the following open-source software. Each is used under its own license; the license notices that ship inside the bundled code are kept there.

| Library | Used for | License |
| --- | --- | --- |
| [CodeMirror 6](https://codemirror.net/) and its [Lezer](https://lezer.codemirror.net/) parsers | the editor | MIT |
| [Lucide](https://lucide.dev/) | icons | ISC |
| [js-yaml](https://github.com/nodeca/js-yaml) | reading and writing note properties and tables | MIT |
| [Turndown](https://github.com/mixmark-io/turndown) | turning web pages into Markdown (web clipper, paste) | MIT |
| [pdfmake](http://pdfmake.org/) (includes [PDFKit](https://pdfkit.org/) and [pako](https://github.com/nodeca/pako)) | saving notes as PDF | MIT |
| [html-to-pdfmake](https://github.com/Aymkdn/html-to-pdfmake) | saving notes as PDF | MIT |
